图标即铅字

铅字厅展出 Font Awesome 的字体图标。每一枚图标都是字库里的一个字形：给文字属性，它就跟着变——字号随 font-size，颜色随 color，像排字工人手里最听话的一枚活字。

本厅展品均以字体方式渲染，全部文件已本地化至 cdn 目录。

字体原理

随字号缩放，无需重绘

同一枚字形，只改 font-size（1.25 / 2.75 / 5.5rem）。它本来就是字，放多大都不会糊。

随文字颜色而变

图标的颜色完全继承 CSS 的 color 属性，与正文文字同源同变。

能排进句子里

在排字工人眼里，图标 与文字 没有身份差别，都按基线排队，都能被选中、复制。
